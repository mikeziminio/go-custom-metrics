

## Build info

При сборке можно указать значение buildVersion, buildDate, buildCommit следующим образом:
```
task build -- -ldflags "-X main.buildVersion=1.0 -X main.buildDate=2026-03-24 -X main.buildCommit=some"
```

## Reset

Пример запуска:
```
# для всех директорий
task reset

# опционально - для конкретной директории
task reset -- ./internal/some_folder
```

### Как работает

`reset` генерирует методы `Reset()` для структур с комментарием `// generate:reset`.

Алгоритм:
1. **Первый проход** — собирает имена всех определений типов (не только struct) в пакете с их типами.
2. **Второй проход** — для каждой структуры с `// generate:reset` генерирует метод `Reset()` с правилами сброса.

Генерирует файл `reset.gen.go` в том же пакете с методами для всех отмеченных структур.

### Ограничения

**Ограничение:** поиск type declarations выполняется только в рамках `текущего пакета`.
Типы из других пакетов (включая `go get` зависимости) не анализируются.

**Возможные решения в рамках текущего кода:**
Расширить алгоритм сбора:
- Рекурсивное сканирование всех пакетов от корня проекта.
- Сканирование внешних пакетов — по `vendor/` и `go.mod`.
- Корректное сопоставление `import` с найденными пакетами.

**Но это выходит за рамки ТЗ по Инкременту 21** и уже приближается к написанию LSP для Go.

Если действительно требуется обойти все эти ограничения, то по-моему мнению имеет смысл рассмотреть запускать отдельного процесса с `gopls` в качестве json-rpc сервера, куда `reset` сможет отправлять команды "textDocument/definition" для  гарантированного получения корректного определения типа.

**Некорректное ТЗ**

Согласно ТЗ Инкремента 21 допустима такая конструкция в Go:

```
type ResetableStruct struct {
   child *ResetableStruct
}

func (rs *ResetableStruct) Reset() {
    resetter, ok := rs.child.(interface{ Reset() })
    ...
}
```

Но type assertion `value.(T)` допустимо только когда `value` является интерфейсом.
Поэтому проверка на наличие метода Reset() была сделана через оборачиванием в интерфейс:

```
resetter, ok := any(rs.child).(interface{ Reset() })
```

## Pool

Пакет `internal/pool` предоставляет generic-контейнер для повторного использования объектов с методом `Reset()`:

- **`Pool[T Resettable]`** — обобщённая структура, хранящая объекты типа `T`
- **`New(func() T)`** — конструктор, принимает функцию создания нового объекта
- **`Get()`** — получает объект из пула (или создаёт новый, если пул пуст)
- **`Put(obj T)`** — возвращает объект в пул (автоматически вызывает `Reset()`)
